**Arc 메인넷 지원 — Circle의 USDC 네이티브 L1, 공개 다음 날부터.** Kura는 이제 Base와 Arc, 메인넷·테스트넷 네 네트워크에서 도는 AI 에이전트 지갑이에요. Arc에선 가스도 USDC라 ETH 없이 바로 써요.

[새로 생긴 것]

• 네 번째 네트워크 「Arc 메인넷」 — 9월 16일에 공개된 Circle의 체인이에요. 설정 → 네트워크에서 고를 수 있어요. 테스트넷과 같이 가스도 USDC로 내요(ETH 잔액 줄·ETH 보내기 없음). 실제 자금이 오가는 체인이라 운영 예산만 소액 충전하세요. 거래소·다른 지갑에서 보낼 땐 반드시 「Arc」 네트워크를 고르세요. 에이전트 신원 조회(ERC-8004)도 여기서 돼요. x402 결제는 아직이에요 — Arc에서 우리 방식(USDC 서명)으로 정산해 주는 곳이 메인넷에도 아직 없어서, 지금은 잔액·송금·신원 조회까지예요.

[바뀐 것]

• Arc 메인넷에서 송금할 때 가스 몫으로 남겨 두는 USDC는 0.05예요(테스트넷은 그대로 0.01). 메인넷 가스가 테스트넷보다 훨씬 비싸요.

• 설정의 네트워크 칸이 넷이 되면서 2×2로 놓였어요 — 윗줄이 실제 자금(Base·Arc), 아랫줄이 연습용(Base Sepolia·Arc 테스트넷)이에요.

• Arc 테스트넷의 거래 내역 링크가 Circle 공식 탐색기(explorer.testnet.arc.io)로 열려요. 전에 쓰던 주소가 이쪽으로 넘어가게 바뀌어서 정본으로 맞췄어요.

[고친 것]

• AI가 에이전트 번호 없이 결제를 요청하면 호출이 튕기던 문제를 고쳤어요 (0.4.0에서 생긴 문제). 번호는 원래 선택 사항이에요.

**Arc mainnet support — Circle's USDC-native L1, from the day after launch.** Kura is now an AI-agent wallet on four networks: Base and Arc, mainnet and testnet. On Arc, gas is USDC too, so it works with no ETH at all.

[What's new]

• A fourth network, 「Arc mainnet」 — Circle's chain, public since September 16. Pick it in Settings → Network. Like the testnet, gas is paid in USDC (no ETH balance line, no ETH send). This one moves real funds, so top up only what the agent needs. When sending from an exchange or another wallet, you must pick the 「Arc」 network. Agent identity lookup (ERC-8004) works there too. x402 payments are not there yet — nobody settles our form (a plain USDC signature) on Arc mainnet either, so for now it is balances, transfers, and identity lookup.

[Changed]

• On Arc mainnet, 0.05 USDC is kept back for gas when you send (the testnet stays at 0.01). Mainnet gas is much dearer than the testnet's.

• With four networks, the Settings picker is now a 2×2 grid — real funds (Base, Arc) on top, practice (Base Sepolia, Arc testnet) below.

• Arc testnet transaction links open Circle's official explorer (explorer.testnet.arc.io). The old address now redirects there, so we point at the canonical one.

[Fixed]

• A payment request from the AI without an agent number was rejected outright (since 0.4.0). Fixed — the number was always optional.
