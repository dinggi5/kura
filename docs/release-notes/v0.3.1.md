[Fixed]

• Payment requests from the AI were being turned down with 「The wallet app isn't running」 when you hadn't touched the wallet window for a while — even though the app was running fine. After the window sat hidden for about five minutes, the app stopped writing its 「I'm alive」 mark. That's exactly the state you're in when a payment comes up mid-conversation with an AI, so it was not a rare case.

• The mark is now written regardless of the window, and if a payment request arrives while the window is asleep, the wallet brings the window forward by itself.

• Fixed the grammar in the version notice (「0.2.2이에요」 → 「0.2.2 버전이에요」).

• When `KURA_CHAIN_ID` pins a chain other than the one in your settings, the saved RPC URL belongs to the other chain, so it is no longer used — the pinned chain's public RPC is used instead. This stops balance lookups from dying for anyone on a custom RPC who switches chains that way.

[Changed]

• Settings 「Agent identity lookup」 now carries the spec name too (ERC-8004), so people searching for the standard can find it.
