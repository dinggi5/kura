[바뀐 것]

• 새로 설치하면 기본 네트워크가 메인넷이에요 — Kura는 AI가 실제 결제를 하는 지갑이라, 첫 화면부터 진짜 지갑으로 시작해요. 안전장치는 그대로예요: 모든 결제는 기본값으로 비밀번호 승인이고, 자율 결제는 꺼져 있고, 한도가 지출을 막아줘요. 연습하고 싶으면 설정 → 네트워크에서 테스트넷으로 바꾸면 돼요. **이미 쓰고 있던 지갑은 쓰던 체인 그대로예요** — 설정을 저장한 적 없는 예전 설치도 테스트넷으로 유지돼요.

• 기본 ETH 한도를 내렸어요 — 신규 설치의 기본값이 단일 0.05 → 0.01, 하루 0.2 → 0.05 ETH로 바뀌어요. 기본이 메인넷(실돈)이 되면서 USDC 한도(5/20)와 축을 맞췄어요. 기존 사용자의 한도 설정은 건드리지 않아요.

• 시작할 때 업데이트 확인이 신규 설치에선 꺼져 있어요 — 이 확인은 깃허브에 요청 한 번을 보내요(현재 버전과 IP가 그쪽에 남아요). 로컬 전용을 내세운 앱이라, 말없이 바깥에 묻지 않는 게 기본이어야 한다고 봤어요. 설정 → 정보에서 켤 수 있고, 켜 두고 쓰던 분들은 그대로 켜져 있어요. (업데이트 설치는 어느 쪽이든 항상 사람이 직접 눌러야 해요.)

• 설정 화면을 정리했어요 — 네트워크 토글은 메인넷이 왼쪽으로 오고, 메인넷을 고르면 실돈 경고가 또렷한 콜아웃으로 떠요. 낱개로 흩어져 있던 토글들은 한 카드 안의 구분선 리스트로 묶고, 숫자 입력엔 단위(USDC·ETH·분)를 필드 안에 붙여 정렬을 통일했어요.

• 결제 승인·기록·한도 검사 로직은 그대로예요 — 이번 버전은 기본값과 화면을 다듬은 릴리스예요.
