**AI가 x402로 검색을 보내고 이미지를 받아 올 수 있어요.**

[새로 생긴 것]

• AI가 x402 서비스에 질문(JSON)을 담아 POST로 요청하고 결제할 수 있어요. 결제한 재요청은 처음과 같은 내용으로 나가요.

• 이미지·PDF 같은 파일 응답은 다운로드 폴더 안 Kura 폴더에 저장돼요. 3MB 이하 PNG·JPEG·GIF·WebP 이미지는 AI도 바로 봐요.

• 서명만 하는 x402 결제가 정산되면, 판매자가 알려 준 정산 거래와 탐색기 링크를 AI도 받아요.

[바뀐 것]

• 라이트 모드 배경의 노란 기를 뺐어요.

• 승인 창과 보내기 확인 화면의 금액을 반올림하지 않고 그대로 보여 줘요.

• x402 결제는 https 주소나 이 맥 안의 주소에서만 해요.

• 서명만 하는 x402 결제는 이미지 생성처럼 오래 걸리는 응답을 3분까지 기다려요.

• 결제 뒤 응답이 중간에 끊기면 받은 만큼 보여 주고, 다시 요청하면 또 결제될 수 있다고 AI에게 알려요.

• 파일 저장이 늦어지면 결과를 먼저 돌려주고, 파일이 생길 자리를 알려요.

• 결제한 응답을 파일로 저장하지 못하면, 다시 요청하면 또 결제된다고 AI에게 알려요.

• 도움말과 README의 예시 서비스를 Exa·AiSpace로 바꿨어요.

[고친 것]

• Arc에서 지갑이 직접 올리는 결제는 영수증을 다시 낼 기록을 먼저 디스크에 남기고, 못 남기면 결제하지 않아요. 결제 중에 앱이 꺼져도 AI가 그 영수증을 다시 낼 수 있어요.

• 서명만 하는 x402 결제는 내역에 기록하지 못하면 서명을 보내지 않아요.

• 보내기 직전의 「확인 필요」 기록을 디스크에 확실히 쓴 뒤에 보내요.

• 결과를 몰랐던 결제가 다음 날 안 나간 걸로 확인될 때 그날 한도를 늘려 주던 문제를 고쳤어요.

• 아주 큰 금액 요청이 작은 금액으로 바뀌어 결제될 수 있던 문제를 고쳤어요. 이제 거절해요.

• 지갑을 만들거나 계정을 더할 때 지갑 파일을 디스크에 확실히 써요.

• 손상된 지갑 파일이 지나치게 큰 계산을 요구하면 열지 않고 오류로 알려요.

**The AI can now send searches over x402 and bring back images.**

[What's new]

• The AI can make POST requests with a JSON body to x402 services and pay for them. The paid retry goes out with exactly the same request.

• File responses such as images and PDFs are saved to a Kura folder inside Downloads. PNG, JPEG, GIF and WebP images up to 3 MB are also shown to the AI directly.

• When a signed-only x402 payment settles, the AI also gets the settlement transaction the seller reports, with an explorer link.

[Changed]

• The light-mode background no longer has a yellow tint.

• The approval window and the send confirmation show amounts exactly, without rounding.

• x402 payments only go to https addresses or addresses on this Mac.

• For signed-only x402 payments, Kura waits up to 3 minutes for slow responses such as image generation.

• If the response breaks off after a payment, the AI gets what arrived and is told that asking again may pay again.

• If saving a file takes long, the result comes back first, along with where the file will appear.

• If a paid response can't be saved to a file, the AI is told that asking again pays again.

• The example services in Help and the README are now Exa and AiSpace.

[Fixed]

• On Arc, a payment the wallet broadcasts itself first saves what it needs to resend the receipt to disk, and doesn't pay if it can't. If the app quits mid-payment, the AI can still resend that receipt.

• A signed-only x402 payment isn't sent if it can't be recorded in History.

• The 「Unconfirmed」 record written right before a transfer is now safely on disk before the transfer goes out.

• Fixed a payment whose outcome was unknown raising the next day's limit when it turned out not to have gone out.

• Fixed a huge amount request that could turn into a small payment. It's now refused.

• Creating a wallet or adding an account now writes the wallet file safely to disk.

• A damaged wallet file that demands an excessive amount of computation is refused with an error instead of being opened.
