**한 번 연결하면 Claude가 늘 Kura를 찾아요. 보통 맥 창으로도 열 수 있어요.**

[새로 생긴 것]

• 메뉴 막대 아이콘을 우클릭해 「창으로 열기」를 고르거나, 작은 창 위쪽의 창 아이콘을 누르면 Kura가 보통 맥 창으로 열려요. 창을 넓히면 내역이 표로 보여요.

• 결제 승인은 큰 창이 떠 있어도 늘 작은 창에서 해요. 큰 창에는 「승인 창 열기」 버튼이 떠요.

• Kura가 꺼져 있어도 AI가 결제를 요청하면 Kura가 뒤에서 켜지고 승인 창이 떠요.

• 지갑을 처음 만들면 「Claude와 연결할까요?」 단계가 나와요. 이 맥에서 찾은 Claude Code·Claude 데스크톱 연결과 로그인 시 자동 시작을 한 번에 켜요.

• Claude Code에 연결해 둔 Kura를 옮기거나 다른 사본을 지웠으면, Kura가 켜질 때 연결을 지금 설치된 Kura로 고쳐요.

[바뀐 것]

• AI 배지가 셋으로 나뉘어요 — 「Claude 쓰는 중」, 「준비됨 · Claude를 켜면 자동으로 붙어요」, 「AI 연결 필요」.

• 연결 화면에서 Claude 데스크톱의 Kura 확장이 꺼져 있으면 「확장 꺼져 있음」으로 보여요.

• 창 두 개 중 한쪽에서 계정·언어·설정·긴급 잠금을 바꾸면 다른 쪽에도 바로 반영돼요.

• 「자리 비우면 자동 잠금」을 켜 뒀어도 Kura 창끼리 오가는 건 자리를 비운 걸로 보지 않아요.

• 보낸 결과를 확인하지 못하면 보내기 화면이 「확인 필요」와 거래 해시를 띄운 채 남아요. 그 화면엔 다시 보내기 버튼이 없어요.

• 보내는 중에는 업데이트를 설치하지 않아요. 끝난 뒤 다시 누르면 돼요.

[고친 것]

• 설정한 RPC 주소가 다른 네트워크 것이면 그 네트워크의 잔액을 보여 주던 문제를 고쳤어요. 이제 잔액 대신 오류를 보여요.

• Arc에서 지갑이 직접 올리는 x402 결제를 늦게 승인하면 돈은 나가고 콘텐츠를 못 받을 수 있던 문제를 고쳤어요. 대신 그 결제는 승인을 기다리는 시간이 짧아질 수 있어요.

**Connect once and Claude always finds Kura. Kura also opens as a regular Mac window.**

[What's new]

• Right-click the menu bar icon and choose 「Open in Window」, or press the window icon at the top of the small window, to open Kura as a regular Mac window. Widen it and History turns into a table.

• Payments are always approved in the small window, even while the big one is open. The big window shows a 「Review」 button.

• If Kura is closed when the AI asks to pay, Kura starts in the background and the approval window appears.

• Right after you create a wallet, Kura asks 「Connect Claude?」 and connects the Claude Code and Claude desktop it finds on this Mac — plus launch at login — in one go.

• If you moved the Kura that Claude Code is connected to, or deleted that copy, Kura points the connection at the installed app when it starts.

[Changed]

• The AI badge now has three states: 「Claude in use」, 「Ready · attaches when you open Claude」 and 「Connect an AI」.

• The connect screen shows 「Extension turned off」 when Kura's extension is turned off in Claude desktop.

• Switching account, language, settings or the emergency lock in one window shows up in the other right away.

• With 「Lock when you step away」 on, moving between Kura's own windows no longer counts as leaving.

• If a transfer's outcome can't be confirmed, the Send screen stays open with 「Unconfirmed」 and the transaction hash. That screen has no button to send again.

• Updates don't install while a transfer is going out. Press it again once it's done.

• An RPC address set to a different network showed that network's balance. It now shows an error instead.

• On Arc, approving a payment the wallet puts on-chain itself late could take the money without delivering the content. Fixed — the approval window for such payments can be shorter now.
