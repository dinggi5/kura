**Claude와의 연결이 쉽게 끊기지 않아요. 보통 맥 창으로도 열 수 있어요.**

[새로 생긴 것]

• 메뉴 막대 아이콘을 우클릭해 「창으로 열기」를 고르거나, 작은 창 위쪽의 창 아이콘을 누르면 Kura가 보통 맥 창으로 열려요. 창을 넓히면 내역이 표로 보여요.

• AI의 결제 요청은 큰 창이 떠 있어도 늘 작은 창에서 승인해요. 큰 창에는 「승인 창 열기」 버튼이 떠요.

• 설치된 Kura로 연결해 뒀다면, Kura가 꺼져 있어도 AI가 결제를 요청할 때 Kura가 뒤에서 켜져요.

• 지갑을 처음 만들면 「Claude와 연결할까요?」 단계가 나와요. 「연결하기」를 누르면 이 맥에서 찾은 Claude Code를 연결하고, 로그인 시 자동 시작을 켜고, Claude 데스크톱엔 확장 설치 화면을 열어 줘요(Claude에서 설치를 한 번 더 눌러요).

• Claude Code가 옮겨지거나 지워진 Kura를 가리키고 있으면, 설치된 Kura가 켜질 때 연결을 자기 쪽으로 고쳐요.

[바뀐 것]

• AI 배지가 셋으로 나뉘어요 — 「(쓰는 앱) 쓰는 중」, 「준비됨 · Claude를 켜면 자동으로 붙어요」, 「AI 연결 필요」.

• 연결 화면에서 Claude 데스크톱의 Kura 확장이 꺼져 있으면 「확장 꺼져 있음」으로 보여요.

• 한쪽 창에서 계정·설정·긴급 잠금을 바꾸면 다른 창에도 반영돼요. 언어는 다른 창으로 돌아갈 때 바뀌어요. 다른 창에서 계정이나 네트워크를 바꾸면, 아직 보내기 전인 보내기 화면은 닫혀요.

• 설정을 저장할 때 다른 창에서 바꾼 항목은 그대로 둬요.

• 「자리 비우면 자동 잠금」을 켜 뒀어도 Kura 창끼리 오가는 건 자리를 비운 걸로 보지 않아요.

• 보낸 결과를 확인하지 못하면 보내기 화면이 「확인 필요」와 거래 해시를 띄운 채 남아요. 그 화면엔 다시 보내기 버튼이 없어요.

• 보내는 중이거나 결과가 떠 있는 동안엔 다른 화면으로 넘어가지 않고, 큰 창도 닫히지 않아요.

• 보내는 중에는 업데이트를 설치하지 않아요. 끝난 뒤 다시 누르면 돼요.

• Arc에서 지갑이 직접 올리는 x402 결제는, 서버가 유효시간을 정해 두었으면 제출과 영수증 전달에 쓸 시간을 남기려고 승인할 수 있는 시간이 짧아질 수 있어요. 승인 창엔 실제로 남은 시간이 보이고, 지나면 보내지 않아요. 다른 송금이 나가는 중이면 그 결제는 보내지 않고 다시 시도하라고 알려요.

[고친 것]

• RPC가 보낸 오류가 「처리됐는지 모른다」는 뜻일 때도 송금을 「실패」로 보던 문제를 고쳤어요. 이제 「확인 필요」로 남기고 한도를 돌려주지 않아요.

• 송금이 나가는 도중 앱이 꺼지면 내역에 그 송금이 남지 않던 문제를 고쳤어요. 이제 보내기 직전에 「확인 필요」로 먼저 적고(못 적으면 보내지 않아요), 앱이 체인에서 결말을 확인해요.

• 지갑 파일 일부가 손상됐을 때 앱이 꺼지던 문제를 고쳤어요. 이제 오류로 알려요.

• 설정한 RPC 주소가 다른 네트워크 것이면 그 네트워크의 잔액이나 에이전트 정보를 보여 주던 문제를 고쳤어요. 이제 오류를 보여요.

• 서명만 하는 x402 결제에서 서버가 정산 실패를 알렸는데도 AI에게 결제가 확인됐다고 말하던 문제를 고쳤어요.

• 오늘 쓴 금액 기록을 못 읽을 때 남은 한도가 가득 찬 것처럼 보이던 문제를 고쳤어요.

**Kura stays connected to Claude more reliably, and now also opens as a regular Mac window.**

[What's new]

• Right-click the menu bar icon and choose 「Open in Window」, or press the window icon at the top of the small window, to open Kura as a regular Mac window. Widen it and History turns into a table.

• The AI's payment requests are always approved in the small window, even while the big one is open. The big window shows a 「Review」 button.

• If you connected the installed Kura, it starts in the background when the AI asks to pay while it's closed.

• Right after you create a wallet, Kura asks 「Connect Claude?」. Pressing Connect hooks up the Claude Code it finds on this Mac, turns on launch at login, and opens the extension installer for Claude desktop (press Install once more in Claude).

• If Claude Code points at a Kura that was moved or deleted, the installed Kura repoints the connection to itself when it starts.

[Changed]

• The AI badge now has three states: 「(app) in use」, 「Ready · attaches when you open Claude」 and 「Connect an AI」.

• The connect screen shows 「Extension turned off」 when Kura's extension is turned off in Claude desktop.

• Switching account, settings or the emergency lock in one window shows up in the other. Language changes apply when you return to the other window. If the account or network changes in another window, a Send screen that hasn't sent yet closes.

• Saving Settings keeps the fields another window changed.

• With 「Lock when you step away」 on, moving between Kura's own windows no longer counts as leaving.

• If a transfer's outcome can't be confirmed, the Send screen stays open with 「Unconfirmed」 and the transaction hash. That screen has no button to send again.

• While a transfer is going out or its result is showing, Kura won't switch screens and the big window won't close.

• Updates don't install while a transfer is going out. Press it again once it's done.

• On Arc, when the server sets a time limit on a payment the wallet puts on-chain itself, the approval time can be shorter, to leave room for submitting it and handing in the receipt. The approval window shows the real time left, and nothing is sent once it runs out. If another transfer is going out, such a payment isn't sent and the AI is told to try again.

[Fixed]

• When the RPC returned an error meaning "not sure it was processed", a transfer was treated as failed. It now stays 「Unconfirmed」 and the limit isn't given back.

• If the app closed while a transfer was going out, the transfer could be missing from History. It's now written as 「Unconfirmed」 right before sending (nothing is sent if that fails), and the app checks the outcome on-chain.

• A partly damaged wallet file could crash the app. It now shows an error.

• An RPC address set to a different network showed that network's balance or agent record. It now shows an error.

• For signature-only x402 payments, the AI was told a payment was confirmed even when the server reported the settlement failed. Fixed.

• When today's spending record couldn't be read, the remaining limit looked full. Fixed.
