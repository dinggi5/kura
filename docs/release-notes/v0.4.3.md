**받은 돈도 내역에 떠요. 나갔는지 모르던 결제는 앱이 체인에서 다시 확인해요.**

[새로 생긴 것]

• 받은 USDC·ETH가 내역에 「받음」으로 떠요. 처음엔 90일 전까지 찾아요.

• 「확인 필요」나 「정산 대기」로 남은 결제를 앱이 체인에서 다시 확인해 결과를 바로잡아요. 돈이 안 나갔으면 「되돌려짐」이나 「만료 · 안 나감」으로 바뀌고, 같은 날이면 오늘 한도도 돌아와요.

• 자율 결제로 같은 곳에 같은 금액을 10분 안에 또 보내려 하면 비밀번호를 물어요. 승인 창에도 「N분 전에 같은 곳으로 같은 금액을 보냈어요」가 떠요.

• Arc에서 결제는 나갔는데 콘텐츠를 못 받았으면, AI가 새 돈 없이 같은 영수증을 다시 낼 수 있어요.

• 내역이 200건을 넘어도 지우지 않아요. 아래 「더 보기」로 이어서 봐요.

[바뀐 것]

• 내역에서 상태 글자(「보냄」·「확인 필요」 등)를 누르면 탐색기가 열려요.

• AI가 도구를 고를 때 읽는 설명을 다듬었어요.

• 설정의 「화이트리스트」를 「신뢰 주소」로 이름을 맞췄어요.

[고친 것]

• 긴급 잠금 파일이 깨져 있으면 잠금이 풀린 것으로 보던 문제를 고쳤어요. 이제 잠긴 것으로 봐요.

• 내역 파일이 깨지면 옛 기록이 지워지던 문제를 고쳤어요. 깨진 파일은 옆에 남겨 둬요.

• 설정 파일 일부가 깨지면 한도가 기본값으로 올라가던 문제를 고쳤어요.

• 오늘 쓴 금액 기록을 못 읽으면 한도를 처음부터 세던 문제를 고쳤어요. 이제 결제를 막아요.

• 계정을 추가하는 사이 다른 저장이 겹치면 방금 만든 계정이 사라질 수 있던 문제를 고쳤어요.

• 신뢰 주소를 지운 게 되돌아올 수 있던 문제를 고쳤어요.

**Money you receive now shows in History. Payments whose outcome was unclear are rechecked on-chain.**

[What's new]

• Incoming USDC and ETH show in History as 「Received」. The first scan looks back 90 days.

• Payments left as 「Unconfirmed」 or 「Awaiting settlement」 are rechecked on-chain and set right. If the money didn't leave, they turn into 「Reverted」 or 「Expired · not paid」, and on the same day your daily limit comes back too.

• If autopay tries to send the same amount to the same place again within ten minutes, Kura asks for your password. The approval window also says 「You sent the same amount here N min ago」.

• On Arc, if a payment went out but the content didn't arrive, the AI can hand in the same receipt again without paying twice.

• History no longer drops anything past 200 entries. 「Show more」 at the bottom loads the rest.

[Changed]

• Tapping a status in History (「Sent」, 「Unconfirmed」, …) opens the explorer.

• The descriptions the AI reads when choosing a tool are clearer.

• 「Whitelist」 in Settings is now called 「Trusted addresses」, like everywhere else.

[Fixed]

• A damaged emergency-lock file was read as unlocked. It now counts as locked.

• A damaged history file could wipe older entries. The damaged file is now kept aside.

• A partly damaged settings file could raise your limits to the defaults. Fixed.

• If today's spending record couldn't be read, limits started counting from zero. Payments are now blocked instead.

• Adding an account while another save was in flight could lose the new account. Fixed.

• A removed trusted address could come back. Fixed.
